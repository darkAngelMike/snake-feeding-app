Dokumentacja projektu

Snake App

Aplikacja do prowadzenia profilu pytona królewskiego, planowania karmienia, rejestrowania historii oraz wyliczania zaleceń na podstawie masy, etapu życia i kondycji.

Frontend React + Vite + Supabase Auth
Backend Node.js + Express + Supabase
Baza danych Supabase / PostgreSQL
Zakres aplikacji Planer, nie porada weterynaryjna

Spis treści

Opis projektu Architektura Główne flow Schemat danych API backendu Logika karmienia Frontend Uruchomienie Testy i jakość Ryzyka

Cel

Opis projektu

Snake App to panel opiekuna gada. Użytkownik zakłada konto, uzupełnia profil węża, oblicza następne karmienie i zapisuje faktyczne karmienia w historii.

Profil węża

Przechowuje imię, aktualną masę, etap życia, kondycję oraz datę ostatniego udanego karmienia.

Plan karmienia

Backend liczy zakres karmówki, interwał, następną datę, ostrzeżenia i status planu.

Historia

Faktyczne karmienia są zapisywane jako osobne wpisy, razem z masą węża i masą karmówki.

Aplikacja działa jako planer i dziennik opieki. Nie zastępuje diagnostyki ani porady weterynarza od zwierząt egzotycznych.

UX

Główne flow aplikacji

  1. Użytkownik loguje się lub rejestruje przez Supabase Auth.
  2. Aplikacja pobiera profil z tabeli snake_profiles.
  3. Jeżeli profil jest niekompletny, użytkownik uzupełnia dane węża.
  4. Dashboard pokazuje aktualną wagę, etap życia, kondycję i datę ostatniego udanego karmienia.
  5. Użytkownik może obliczyć plan karmienia przez endpoint /calculate.
  6. Wynik kalkulacji może zostać zapisany w feeding_calculations.
  7. Faktyczne karmienie jest zapisywane w feedings.
  8. Historia karmień jest wyświetlana jako timeline.

Reguły

Logika karmienia

Reguły są zaimplementowane w server/services/feedingService.js. Wynik jest orientacyjnym planem, a nie diagnozą.

Etap życia Zakres karmówki Interwał
hatchling12-15% masy ciała5-7 dni
juvenile10-15% masy ciała7-10 dni
subadult10-12% masy ciała10-14 dni
adult8-10% masy ciała14-21 dni

Kondycja

  • underweight używa górnej części zakresu i dodaje ostrzeżenie.
  • normal używa środka zakresu.
  • overweight używa dolnej części zakresu; dla dorosłych 6-8%.

Ostrzeżenia

  • Dwie lub więcej odmów karmienia.
  • Wylinka, która może wpływać na apetyt.
  • Ostatnia karmówka powyżej 15% masy ciała.
  • Skrajna niespójność etapu życia z masą.

Uwagi techniczne

Znane ryzyka i następne kroki

Endpoint /calculate obecnie zwraca wynik kalkulacji niezależnie od tego, czy zapis do feeding_calculations zakończy się sukcesem. Błąd zapisu jest logowany po stronie backendu.

Rekomendowane usprawnienia

  • Ustalić, czy zapis kalkulacji ma być wymagany, czy best-effort.
  • Przenieść adres backendu i klucze Supabase do zmiennych środowiskowych.
  • Zweryfikować RLS dla snake_profiles, feedings i feeding_calculations.
  • Dodać jawny status zapisu kalkulacji w odpowiedzi API.
  • Dodać daty created_at i updated_at tam, gdzie ich brakuje.
